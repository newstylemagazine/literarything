# Facingpage

Facingpage is a polished browser prototype for public-domain bilingual reading editions.

## What it does

- Browses a starter catalog of canonical works in French, Italian, German, Spanish, and Latin.
- Renders a facing-page reader with original-language text on one side and English on the other.
- Exports the current edition to PDF from the browser.
- Captures text selection as a placeholder for future word-by-word glossing.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a static server such as `python3 -m http.server 4173` and visit `http://localhost:4173`.
